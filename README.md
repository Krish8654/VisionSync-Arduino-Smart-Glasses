# VisionSync Arduino Smart Glasses

## Overview
VisionSync is a smart glasses project built using Arduino Nano, HC-05 Bluetooth Module, OLED Display and an Android Application.
The system displays real-time information from a smartphone directly on a wearable OLED display.

## Features

- Real-Time Clock
- Bluetooth Communication
- Notification Display
- Incoming Call Alerts
- OLED Display Interface
- Android Companion App

## Hardware Components

- Arduino Nano
- HC-05 Bluetooth Module
- 0.96" OLED Display
- Rechargeable Battery
- Smart Glasses Frame

## Software Stack

- Arduino IDE
- Android Studio
- Java
- XML
- Bluetooth Serial Communication

## Project Architecture

Android App

↓
Bluetooth HC-05

↓
Arduino Nano

↓
OLED Display
